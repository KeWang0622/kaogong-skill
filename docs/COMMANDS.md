# 命令速查

[← 回到首页](../README.md) · [使用示例](EXAMPLES.md) · [安装指南](INSTALL.md)

自然语言就能开始训练。下面这些快捷命令由 **Claude Code 插件**提供；命令菜单中可能带插件命名空间。只安装技能目录的用户，用相应的自然语言提问即可。

| 命令 | 用途 | 可以接着说 |
|---|---|---|
| `/kaogong` | 入门诊断 | 我想考事业编，但还不知道考什么 |
| `/kaogong-xingce` | 行测 | 来一道资料分析题，先不给答案 |
| `/kaogong-shenlun` | 申论 | 按材料批改我的概括题答案 |
| `/kaogong-zhice` | 职测 | 我考事业单位 C 类，练数量分析 |
| `/kaogong-zongying` | 综应 | 我考 B 类，练论证评价 |
| `/kaogong-gongji` | 公基 | 出一道公文多选题，先说计分规则 |
| `/kaogong-gongwen` | 公文 | 帮我分清请示和报告 |
| `/kaogong-mianshi` | 面试 | 来一道基层服务场景的应急题 |
| `/kaogong-shizheng` | 时政 | 分析这篇新闻可以怎样用于申论 |
| `/kaogong-baokao` | 报考 | 帮我读这份公告和岗位表 |
| `/kaogong-plan` | 学习计划 | 每天一小时，安排第一周复习 |
| `/kaogong-review` | 错题复盘 | 整理刚才的错题，导出学习卡 |

在 Codex 中，可以用 `$kaogong` 显式选中技能，再描述需求，例如：

```text
$kaogong 我考事业单位 A 类，请给我一道职测判断题。
```

已经有题目或答案时直接贴上来，批改主观题时同时附上材料。考试地区、年份和类别已说明过，就不必每次重填。
