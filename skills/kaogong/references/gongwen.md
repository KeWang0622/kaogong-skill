# 公文 · 知识、改错与考试写作

## 权威依据与范围

- 🟢 [《党政机关公文处理工作条例》](https://www.miit.gov.cn/xwdt/szyw/art/2020/art_6afb8ee6d07540dcacccbeb47dbc0fd4.html)：重点核对第八条文种、第九至十一条格式、第十四至十七条行文、第十八至二十条拟制、第二十三至二十六条办理。
- 🟢 [GB/T 9704—2012《党政机关公文格式》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F3CC9BEF482524C895FDA7A08BB4A70E)：国家标准平台在 2026-10-11 核验时标为现行。涉及纸张、版心、字号、页码等细节须查标准正文，不凭记忆杜撰参数。

本模块面向公基、综应、申论的公文考试任务。申论中的倡议书、讲话稿、工作方案等应用文，并不都属于条例第八条列明的文种。答题要求“只写正文”“不考虑格式”时，不强行添加完整机关制发要素。

## 文种辨析

条例列明的 15 种：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。先判断目的和机关关系，不凭标题尾词或“涉及上级”猜文种。

| 易混项 | 判断问题 |
|---|---|
| 请示 / 报告 | 目的是请求上级指示批准，还是汇报、反映情况？报告不能夹带请示 |
| 批复 / 函 | 是回应下级请示，还是不相隶属机关的往来？函也可涉及请求批准 |
| 通知 / 通报 | 侧重传达执行安排，还是表彰、批评、告知重要情况？ |
| 公告 / 通告 | 是否面向国内外宣布重要或法定事项，还是一定范围内的周知遵守事项？ |
| 决议 / 决定 | 是否为会议讨论通过的重大决策，还是作出重要部署、奖惩等决定？ |
| 纪要 / 会议记录 | 纪要提炼会议主要情况及议定事项；不能把原始发言逐字记录直接当成纪要 |

上表为条例第八条的教学归纳；具体使用仍须结合原文适用范围。

## 行文与办理知识

依条例第十四、十五条：行文关系看隶属与职权；通常不越级，特殊越级须按规定抄送；上行文原则上主送一个上级；请示一文一事。不要把“通常”“原则上”的规则改成没有例外的绝对命题。

教学上可按“文种—对象—内容—程序”四项复核。公文拟制包括起草、审核、签发；收文办理与发文办理分别查第二十四、二十五条，不将两条流程混成一个通用顺序。

## 写作和改错流程（教学建议）

1. **审题**：发文主体、受文对象、隶属关系、事由、文种、字数、是否要求格式。
2. **取材**：列出必须表达的事实、待解决问题和任务；不擅造机关权限、批复结果、文号、日期或金额。
3. **组织**：标题与目的对应；正文交代必要背景、具体事项、执行要求。仅在本题需要时补主送、落款、日期等。
4. **复核**：文种是否合适、指令是否可执行、责任与时间是否明确、称谓与语气是否符合关系。
5. **改错反馈**：逐条列“原文片段—问题—制度依据或教学理由—建议改法”。缺少关键背景时给条件式修改，不能凭空改动事实。

训练量表可按本题目的分为内容、文种与关系、必要格式、语言四项，出题时确定权重。不能把“通知必须扣 5 分格式分”之类的训练设计称为全国规则。

## 模拟原创题：文种改错

**题目**：某单位拟向其上级主管部门提交《关于申请增设周末服务窗口的报告》。正文结尾为“拟新增两个窗口，所需设备预算及人员安排详见附件，请批准”。请指出文种问题并修改标题；假设全文只申请此一事项。

**解析（作答后展示）**：核心是申请批准，宜改为《关于增设周末服务窗口的请示》。依据条例第八条、第十五条。还应核对预算、人事等事项是否在该受文机关审批权限内；题干未给，不自行断言全部可批。不能仅把结尾改为“特此报告”来掩盖实际请求批准的目的。

## 与其他模块衔接
