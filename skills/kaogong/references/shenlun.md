# 申论 — 题型与评分标准完整参考

## 考试概况

- **国考**：自 2022 年起分**副省级、地市级、行政执法类**三套卷，各 150 分钟，满分 100 分
  - **副省级**：宏观议题，要求从国家战略层面分析问题
  - **地市级**：侧重基层治理，强调执行与落实能力
  - **行政执法类**：围绕依法办事、公共服务展开；大作文并非每年必考（2022 年考应用文「公开信」，2023 年恢复大作文）
- **省考**：通常一套，150 分钟，满分 100 分
- **材料**：6000-8000 字的给定资料（通常 6-8 则）
- **题量**：4-5 道题

## 题型详解与评分标准

### 第一题：概括归纳题（10-15 分）

**常见提问方式：**
- "请根据给定资料X，概括……的主要问题/原因/措施/特点"
- "请归纳给定资料X中……的主要内容"

**字数要求**：通常 150-250 字

**评分标准：**
- **踩点给分为主**：阅卷老师按照参考答案的要点逐一对照
- 要点齐全（核心要点通常 4-6 个，每个要点 2-3 分）
- 表述准确（使用材料中的关键词，不要过度发挥）
- 条理清晰（分条作答，序号标注）
- 字数超出扣分

**答题方法：**
1. 审题：明确概括对象（问题？原因？对策？特点？）和材料范围
2. 阅读材料：标注关键信息，区分现象和本质
3. 整合加工：合并同类项，分条列点
4. 规范书写：总括句 + 分点表述（序号+关键词+具体阐述）

---

### 第二题：综合分析题（15-20 分）

**常见提问方式：**
- "请谈谈你对'……'这句话的理解"
- "请对……这一现象进行分析"
- "请分析……的原因/影响"

**字数要求**：通常 200-350 字

**评分标准：**
- 观点明确（对分析对象有清晰判断）
- 分析深入（不停留在表面，要揭示本质和深层原因）
- 逻辑严密（层次清楚：提出观点→分析论证→得出结论/对策）
- 要点完整

**答题结构：**
1. 亮明观点/解释含义（是什么）
2. 多角度分析（为什么：原因/影响/现状）
3. 提出对策或总结（怎么办）

---

### 第三题：提出对策题（20 分）

**常见提问方式：**
- "请针对……问题，提出解决措施"
- "请就……提出对策建议"

**字数要求**：通常 300-400 字

**评分标准：**
- **针对性强**：对策必须针对材料中的具体问题，一一对应
- **可行性高**：措施要具体可操作，不能空喊口号
- **条理清楚**：分条作答，逻辑合理
- 对策来源：材料直接提到的 + 根据问题反推的

**对策要素公式：**
主体 + 手段 + 内容 + 目的

例："政府部门（主体）应建立健全监管机制（手段），加强对网络平台的日常巡查和专项整治（内容），切实保障消费者合法权益（目的）。"

---

### 第四题：应用文写作（20-25 分）

**常考应用文类型：**

| 类型 | 格式要点 |
|------|----------|
| **倡议书** | 标题 + 称谓 + 正文（背景+倡议内容）+ 落款 |
| **讲话稿** | 标题 + 称谓 + 开场白 + 正文 + 结束语 |
| **工作方案** | 标题 + 背景/目的 + 具体措施 + 保障措施 |
| **调研报告** | 标题 + 调研背景 + 现状/问题 + 原因分析 + 对策建议 |
| **短评/简报** | 标题 + 正文（事件+分析+评价） |
| **通知** | 标题 + 主送单位 + 正文 + 落款（发文单位+日期） |
| **建议书** | 标题 + 称谓 + 正文（问题+建议）+ 落款 |

**字数要求**：通常 400-600 字

**评分标准：**
- 格式正确（5分左右）：标题、称谓、落款等是否齐全规范
- 内容完整（10-15分）：要点是否覆盖全面
- 语言得体（3-5分）：符合文种特点（如倡议书要有号召力，讲话稿要亲切）

---

### 第五题：大作文（35-40 分）

**考查形式：**
- 根据给定资料和对某一主题的理解，写一篇议论文
- 字数要求：1000-1200 字（国考）；800-1000 字（部分省考）
- 标题通常自拟

**评分等级：**

| 等级 | 分数 | 标准 |
|------|------|------|
| **一等** | 30-40分 | 立意深刻，见解独到；论证充分，说服力强；语言流畅，表达精准；结构严谨，逻辑清晰 |
| **二等** | 21-29分 | 立意明确，有一定见解；论证较充分；语言通顺；结构完整 |
| **三等** | 11-20分 | 立意基本正确；有一定论证但不充分；语言基本通顺；结构基本完整 |
| **四等** | 0-10分 | 偏题或跑题；论证混乱；语言不通顺；字数严重不足 |

**大作文评分细则（参考）：**

- **标题**（约2分）：准确体现主题，简洁有力
- **开头**（约5分）：引出话题，亮明总论点，语言有吸引力
- **分论点段落**（通常3个，各约8分）：
  - 分论点明确（2分）
  - 论证充分（举例+道理，4分）
  - 与总论点关联（1分）
  - 语言表达（1分）
- **结尾**（约3分）：回扣主题，升华总结
- **语言与逻辑**（约6分）：用词准确、句式灵活、过渡自然

**扣分项：**
- 错别字：每出现 3 个扣 1 分，最多扣 2 分
- 字数不足：每少 50 字扣 1 分
- 未写标题：扣 2 分
- 三段论（只有开头、一大段正文、结尾）：结构分极低

**大作文写作模板：**

```
标题（体现核心观点）

第一段【开头，约150字】
引出背景/现象 → 分析重要性/紧迫性 → 亮明总论点

第二段【分论点一，约250字】
分论点句 → 分析阐述 → 举例论证 → 回扣分论点

第三段【分论点二，约250字】
分论点句 → 分析阐述 → 举例论证 → 回扣分论点

第四段【分论点三，约250字】
分论点句 → 分析阐述 → 举例论证 → 回扣分论点

第五段【结尾，约100字】
总结全文 → 回扣主题 → 展望升华
```

---

## 申论通用评分细则

- **踩点给分**：小题（概括、分析、对策、应用文）以要点为主要赋分依据
- **结构分**：答案是否层次清晰、分条列点
- **语言分**：表述是否准确规范、简洁有力
- **卷面分**：字迹工整可加印象分，潦草难辨会影响评分
