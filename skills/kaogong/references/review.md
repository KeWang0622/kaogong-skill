# 错题复盘与学习记录

以下是本项目教学设计，不是官方考试规定。使用当前对话和用户主动提供的记录；不知道的进度标“未提供”。

## 从证据归因

| 观察到的情况 | 可检验的错因 | 下一项练习 |
|---|---|---|
| 不知道概念或公式 | 知识缺口 | 一张概念卡 + 一个直接应用题 |
| 理解知识却忽略题目限制 | 审题或条件遗漏 | 先只标条件，再解一题 |
| 思路对、数值错 | 计算/单位错误 | 同一方法换数据，保留单位 |
| 能做对但用时长 | 方法选择或熟练度 | 对比两种解法，再做短时练习 |
| 主观题空泛或跑题 | 材料提取/身份/任务偏离 | 重写一个要点并标材料依据 |
| 只选了答案、没给思路 | 原因暂不明确 | 先询问关键一步，不强行诊断 |

题目本身歧义、材料不全或参考答案错误，记录为“题目待修”，不计入学生能力判断。记忆答案后的原题正确率不能直接当作迁移能力提升。

## 复测流程

1. 每道错题只写一条最关键的纠正动作。
2. 当场用一个变式确认理解，复测时隐藏原答案。
3. 可建议次日、数日后、一周后再测；按表现调整，不宣称固定间隔适合所有人。
4. 分模块报告答对数/有效作答数、用户自报用时、重复错因；小样本不预测考试成绩。
5. 用户要求复习计划时，把旧错题复测与新题安排在每日预算内。

## 可复制的学习卡

```text
目标：考试/年份/地区/类别（未知项写未确定）
记录日期：
已完成：科目、题型、有效作答数、答对数
用时：用户自报；未提供则空缺
本次错因：证据 + 待确认项
题目卡：编号、题干或来源、本人答案、正确答案、关键条件
纠正动作：
下次复测：日期或相对间隔 + 变式题型
资料版本：政策/法律/考纲出处与日期
```

短卡应包含足够恢复训练的题干或可访问来源，不能只留“第3题错了”。用户要导出时可输出 Markdown/CSV 文本；文件保存依客户端能力和用户请求，不在后台上传到公共题库。跨会话继续时请用户带回学习卡，不承诺永久记忆或定时提醒已经设置。
