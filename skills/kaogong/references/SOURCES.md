# 参考来源 Sources

本技能的考试内容尽可能对标**官方文件与权威报道**。来源按可信度分三级标注，使用时请注意区分。

| 级别 | 含义 |
|---|---|
| 🟢 **官方** | 法律法规、部委规章、政府网站发布的公告与文件 |
| 🟡 **权威媒体** | 新华社、人民网、中国青年报等对官方数据的报道 |
| 🟠 **行业整理** | 培训机构对历年真题的统计归纳，**非官方口径，仅供参考** |

> ⚠️ **时效性声明**：政策、时间、人数、年龄条件逐年变化。本文件记录的是撰写时可核实的信息，**报考决策请一律以当年官方公告为准**。发现过时内容欢迎提 Issue。

## 四、本技能内容的性质说明

- 练习题为**模拟原创题**，不是真题，不得声称为「某年真题」。
- 申论、综应、公文、面试评分为**本项目训练量表**，除非提供本题公开官方细则，否则不能称为官方标准；分数不预测实际考试成绩。
- 时政、法律、报考政策使用时核对官方版本；离线时明确未核验，不生成最新事实。
- 教学方法、原创模拟题与学习卡属于项目设计，**不是行业统计**，不要求虚构出处。题中制度性事实仍须有来源。

## 五、如何为本项目补充来源

修改制度性考试内容时，请在 PR 中附上出处，并按上表的三级标注注明可信度。优先级：**官方文件 > 权威媒体 > 行业整理**。没有出处的制度性事实不予合并；原创题和训练量表说明设计依据，不虚构来源。详见 [CONTRIBUTING.md](../../../CONTRIBUTING.md)。
