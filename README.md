# 考公AI导师 (kaogong-skill)

**每年数百万人考公，培训班收费1-3万元。这个免费的 Claude Code skill 想改变这一切。**

Millions of Chinese citizens take civil service exams (公务员考试) every year. Traditional prep courses cost 10,000-30,000 RMB. This free Claude Code skill provides comprehensive, exam-accurate tutoring for the Chinese civil service exam — covering 行测 (aptitude test), 申论 (essay writing), and 面试 (structured interview).

---

## 为什么需要这个 Skill？

- **2025年国考报名人数超过300万**，竞争激烈程度逐年递增
- 培训班费用高昂（线下班1-3万元），但并非人人负担得起
- 越来越多年轻人已经开始用AI工具替代传统培训
- 目前 **没有任何一个 Claude Code skill** 针对公务员考试备考
- AI可以提供 **一对一、随时随地、完全免费** 的辅导体验

## 功能模块

### 行测训练 (Administrative Aptitude Test)
- **常识判断**：政治、法律、经济、历史、文化、地理、科技全覆盖
- **言语理解**：逻辑填空（近义词辨析、成语、语境分析）+ 片段阅读六大题型
- **数量关系**：数字推理 + 12种高频数学运算题型及解题技巧
- **判断推理**：图形推理、定义判断、类比推理、逻辑判断（必然性+可能性推理）
- **资料分析**：速算技巧（截位直除、特征数字法、错位加减）+ 核心统计概念

### 申论批改 (Essay Writing & Grading)
- **五大题型全覆盖**：概括归纳、综合分析、提出对策、应用文写作、大作文
- **严格按真实评分标准批改**：踩点给分 + 结构分 + 语言分
- **大作文四等评分**：一等(30-40分)到四等(0-10分)，细化到标题、开头、分论点、结尾
- 提供参考答案和改进建议

### 面试模拟 (Structured Interview Simulation)
- **五大题型**：综合分析、计划组织、人际沟通、应急应变、自我认知
- **七维度评分**：综合分析(20%)、言语表达(20%)、计划组织(15%)、人际交往(15%)、应变能力(15%)、举止仪表(10%)、专业能力(5%)
- 逐维度点评 + 参考答案框架

### 时政热点 (Current Affairs Analysis)
- 五大维度分析框架（政治/经济/社会/文化/生态）
- 关联党的二十大报告、政府工作报告等核心文件
- 预测出题角度

### 个性化学习计划 (Personalized Study Plan)
- 根据考试时间、每日可用时间、薄弱环节定制
- 分阶段规划：基础期 → 提高期 → 冲刺期
- 细化到每日任务，动态调整

## 使用示例 Usage Examples

### 行测练习

```
你: /kaogong-xingce

AI: 请选择要练习的模块：
1. 常识判断
2. 言语理解与表达
3. 数量关系
4. 判断推理
5. 资料分析

你: 2

AI: 言语理解与表达 — 请选择题型：
1. 逻辑填空
2. 片段阅读（主旨概括）
3. 片段阅读（意图判断）
4. 片段阅读（细节理解）
5. 语句排序
6. 语句衔接

你: 1

AI: 【逻辑填空】

在互联网时代，信息传播的速度______，一条新闻可以在几分钟内传遍全球。
然而，信息的真实性却常常______，虚假新闻和谣言______，给社会带来了
不小的困扰。

A. 今非昔比  令人堪忧  层出不穷
B. 一日千里  难以保证  屡见不鲜
C. 突飞猛进  无法辨别  比比皆是
D. 日新月异  参差不齐  此起彼伏

你: B

AI: ✓ 正确！

【解析】
第一空：形容信息传播速度快。"一日千里"形容发展速度极快，用于描述
信息传播速度恰当。"突飞猛进"侧重进步，"日新月异"侧重变化，语境
侧重"速度"而非"变化"，排除C、D。"今非昔比"侧重今昔对比，不直接
形容速度，排除A。

第二空："信息的真实性难以保证"搭配恰当，表示真实性存疑。
"令人堪忧"语义重复（"堪"已有"令人"之意），排除A。

第三空："屡见不鲜"指经常看到，不感到新奇，用于形容虚假新闻频繁
出现很恰当。

【方法总结】逻辑填空解题三步走：
1. 语境分析 → 把握感情色彩和语义方向
2. 辨析差异 → 找选项间的关键区别
3. 代入验证 → 确认搭配是否恰当
```

### 申论批改

```
你: /kaogong-shenlun

AI: 请选择申论题型：
1. 概括归纳题
2. 综合分析题
3. 提出对策题
4. 应用文写作
5. 大作文

你: 1

AI: 【概括归纳题】（15分）

[给出约1000字的材料，关于某城市基层治理的问题...]

题目：请根据给定资料，概括当前城市基层治理中存在的主要问题。
要求：全面准确，条理清晰，不超过200字。

你: [提交答案]

AI: 【批改结果】得分：11/15

✓ 优点：
- 答案分条列点，条理清晰（结构分满分）
- 准确提到了"人员不足"和"经费紧张"两个核心要点

✗ 不足：
- 遗漏要点：未提及"权责不对等"问题（-2分）
- 遗漏要点：未概括"居民参与度低"（-1分）
- 表述可优化："管理混乱"过于笼统，应具体化为"多头管理、职责交叉"（-1分）

【参考答案】
城市基层治理主要存在以下问题：一是权责不对等，基层承担大量上级
下派任务但缺乏相应权力和资源；二是人员不足，社区工作者数量少、
待遇低、流动性大；三是经费紧张，财政投入不足制约服务水平提升；
四是多头管理，部门职责交叉导致推诿扯皮；五是居民参与度低，自治
意识薄弱，社区治理缺乏群众基础。
```

## 内容准确性

本 skill 的考试内容严格对标真实考试标准：

- **行测**：五大模块题型分类、题量、时间分配均依据国考真题
- **申论**：评分标准参照国考阅卷评分细则（踩点给分制、大作文四等评分）
- **面试**：结构化面试评分维度和权重依据国家公务员局相关规定
- 练习题难度对标真题水平，不降低也不拔高

## 项目愿景 Why This Exists

公务员考试是中国最重要的人才选拔考试之一。备考不应该是只有付得起高价培训费的人才能享有的特权。

AI 技术让优质教育资源的普惠成为可能。这个 skill 的目标是：

1. **降低备考门槛**：零成本获得专业辅导
2. **个性化学习**：根据每个人的情况定制训练方案
3. **随时可用**：不受时间地点限制，想学就学
4. **持续更新**：跟随考试动态和政策变化不断迭代

Civil service exams are one of the most important talent selection mechanisms in China. Quality exam preparation should not be a privilege reserved for those who can afford expensive training courses. This skill aims to democratize access to professional-grade tutoring using AI.
